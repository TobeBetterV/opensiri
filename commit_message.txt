feat(opensiri): migrate Easydict client and add Smart Screenshot

openSiri previously held only the website, with no macOS client in the repository. This migrates the Easydict client into the repository root, completes the rebrand, and layers conversation structuring on top of screenshot translation as the input for the upcoming AgentTeams reply feature.

The migration covers 51 path renames and content rewrites across 601 files: directories, the Xcode project, workspace, xcconfig, entitlements, bridging header and Pods support files all become OpenSiri, the bundle identifier becomes com.opensiri.OpenSiri, the URL scheme becomes opensiri, and the Sparkle feed points at this repository. The 66 references to upstream issues, pull requests and wiki pages are kept verbatim because they document why the code looks the way it does, and 486 izual copyright notices are preserved as GPL-3.0 requires. The upstream author's Apple team, Firebase project, Sparkle public key and shared API keys are cleared to placeholders so the fork cannot spend their quota or send user data to their accounts. App, menu bar and about-panel icons now use openSiri brand assets.

Smart Screenshot is new: the former screenshot translation is renamed "Smart Screenshot Beta", and once OCR text reaches the query input a second recognition pass runs asynchronously with geometry intact, structuring WeChat's left/right bubble layout into a ConversationSnapshot. A "Detected WeChat chat" chip appears at the bottom left of the input, where the reading can be corrected to plain text or opened in a review window to fix speakers and text line by line. The query waits for that reading to settle, so one capture is translated exactly once.

Three defaults also change: the selection query's excluded languages become a multi-select that excludes nothing by default, click-to-query is on by default and its setting is hidden, and the side floating window is centered by default. The screen recording "already requested" flag moves from persisted to per-launch so a TCC reset or a re-signed build can request access again.
